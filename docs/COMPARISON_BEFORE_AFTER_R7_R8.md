## 一、一句话总览

**优化前**：能力面（147 端点 / 47 通道 / 50 守护）远超运行面，但存在
**检索口径分裂、分层覆盖 11%、6 个默认关闭**的隐性缺陷——"宣称能力"
与"运行事实"脱节。

**优化后**：13 项落地（R7 六项 + R8 七项），检索口径统一、分层 100%
覆盖、7 个默认开关全部打开、3 个加密副作用缺陷被回归捕获并修复，
**宣称能力与运行事实对齐**；全量测试 1072 → 1120 passed，零回归。

## 八、结论

**13 项优化全部落地并验证，核心成果**：
1. **数据一致性**：检索口径统一（86% 归档不再被命中）、分层 100% 覆盖、
   冲突检测/导出/PII 脱敏在加密下全部恢复——这是本轮最大的实质收益，
   直接修复了"用户删了还搜得到、归档了还命中"的信任缺陷；
2. **默认开关**：7 个"已实现默认关"全部打开，宣称能力即运行能力；
3. **安全与成本**：存储加密默认开启、投毒写入过滤上线、prompt cache
   前缀管理就位（DeepSeek 行情 2 折）；
4. **质量护栏**：全量 1,120 passed / 0 failed，加密副作用被回归捕获
   （教训：默认开关类改动必须跑全量而非定向）。
