## 二、新方案能优化的 10 个点（差距分析）

### ① 波次算法升级（现状 → 7 因素算法）
```
现状: 波次基本聚合（业务流正确但算法未深化）
优化: 波次划分 7 因素（相似度/承运商/时效/大小/优先级/库区/设备）
     + 拣货路径优化（S 型/返回型——行走 -30-50%）
     + 播种墙二次校验（错发率→万分之一）
价值: 拣货效率 +30-50% / 错发率大幅下降
```

### ② 库存防超卖（现状 → 原子扣减）
```
现状: 库存扣减逻辑基础（未确认高并发原子性）
优化: Redis DECR 原子扣减 + 乐观锁 CAS + 热点 Key 分片
     + 库存状态完整（可用/冻结/在途/锁定 + 预占→核销）
价值: 大促高并发零超卖 / 库存状态清晰
```

### ③ AI 智能层（现状 → 2026 AI WMS）
```
现状: AI 层已对标（五维之一）但功能深度待确认
优化: 预测性补货（SS=Z×σ×√LT / ROP / EOQ 公式）

     + 大模型辅助（自然语言查库存/生成指令）
价值: 补货精准 / 库位自优化 / 操作自然语言化
```
