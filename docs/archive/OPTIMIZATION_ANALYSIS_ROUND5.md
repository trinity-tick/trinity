## 二、网络新视角 → Trinity 差距

### 2.1 记忆 × RAG 融合（调研 1）
- **共识：分层而非混同**——RAG 静态知识 / 记忆交互事实，共享检索栈但语义分离
  （Mem0 官方立场）。Trinity 定位（记忆层）与共识一致 ✅；
- **文档知识库导入**：Mem0 已支持文档导入（H1 hybrid+实体抽取）；
  Trinity 无文档解析层（R7 已论证不做）——**差距确认但维持定位**；
- **主动记忆**（proactive retrieval，该记才记/该取才取）：2026 产品化方向
  （CogniFold 等）——Trinity 有 proactive_prefetcher 储备但未接运行路径
  （孤儿清单曾列）→ **可选接入**。

### 2.2 长程任务级评测（调研 1）
- **LOCOMO-Plus beyond-factual**：时序推理/联系建立（arXiv:2602.10715）；
- 关键现实：**"最简长上下文基线仍压过复杂记忆架构"**，但**超百万 token
  跨窗口关联场景外置记忆明显占优**——Trinity 的定位（外部记忆=持久真源）
  与"记忆真正赢的场景"一致 ✅；
- 启示：Trinity 的 LongMemEval-S 78% 已是检索型索引优势的体现；**BEAM
  （1M/10M）正是"记忆赢的场景"——网络恢复后补跑价值被再次确认**。

### 2.3 商业化产品化差距（调研 2）

## 四、确认的取舍（非缺陷）
- **PersonaEngine 默认 off**：网络提示与主流相反——但这是**成本/隐私取舍**
  （LLM 画像构建按需），非缺陷；是否反转需产品决策；
- **无文档解析层**：R7 论证（RAGFlow 强项），本轮再次确认与"分层而非混同"
  共识一致；
- **无托管控制台/计费**：自托管定位，非目标。

## 五、收敛判断

**第五轮结论：优化空间仍在，但已显著收窄且转向"资产利用 + 产品化细节"**：
1. **P0 两项**（AGENTS.md 入维护链、安全守卫接入）是 1 天内的确定性增量；
2. **P1 三项**（Persona 评估、全集导出反锁定、聚合池 ACL）对齐 2026 商业化
   与融合共识，各 1-2 天；
3. **P2 方向性**（主动记忆、文档导入、Mem0 兼容）按定位取舍；
4. **已确认无差距**：检索/QA 分数（天花板）、成本结构（最省档）、安全默认
   （加密/投毒/审计链可验证）、评测口径（最可信一档）、分层定位（与共识一致）。

**一句话：五轮对比后，"能力差距"已穷尽，剩余是"已实现资产的激活 + 产品化
细节打磨"——P0 两项 + P1 三项做完，Trinity 的资产利用率与 2026 商业化
共识将完全对齐。**
