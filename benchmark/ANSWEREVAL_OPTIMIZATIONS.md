# AnswerAcc 生成侧优化实验记录（2026-09-01 第一轮）

> 基线：500q × deepseek-chat，top_k=10，默认配置 → AnswerAcc=0.712（MS=0.163 为最大洼地）

## 实验矩阵

| 实验 | 配置 | AnswerAcc | 结论 |
|---|---|---|---|
| 基线（全类目） | top_k=10, ctx=600 | 0.712（MS 0.163 / SS-P 0.583 / TR 0.725） | — |
| **E1 MS 增强** | MS: top_k=20 + ctx_len=900 | **MS 0.425**（+26 点，2.6×） | ✅ 弱类目加上下文是正路 |
| E2 SS-P 剪枝 | ctx_n=5（全类目通用参数） | SS-P 0.500（−8 点） | ❌ 裁剪伤偏好题 |
| E3 TR 剪枝 | ctx_n=6 | TR 0.688（−4 点） | ❌ 时序题需全上下文 |

## 结论（与历史教训一致）
1. **弱类目（MS）的正确方向是加上下文，不是减**——上下文裁剪对 SS-P/TR 均为负优化
   （同族教训：v6"改格式是负优化"）。
2. 口径统一实证：quality-gate 补 keyword_r10=0.992 后与 answer_eval 旧口径（0.992）
   完全一致——此前 0.916 vs 0.992 是 top-5 vs top-10 口径差。
3. 固化：maintenance answer-eval 任务采用 `--ms-top-k 20 --ms-ctx-len 900`（周日自动）。

## 下一步候选（MS 0.425 仍有 57.5% 生成缺口）
- MS 切片进一步加长（1200）或 top_k=30 的边际收益
- MS 专用 judge（完整性）在生成侧改善后再评估（此前回滚过：0.0 < judge_facts 0.237）
- 全量 500q 最佳配置重跑 → 新整体基线（进行中）

## 第二轮发现（2026-09-01 14:1x）——MS 全量/独立跑不稳定（已用 empty 追踪闭环）
- MS 单独跑稳定在 0.39-0.44（top_k 10 与 20/900 无显著差异——配置效果是噪声级）
- 全量 500q 跑中 MS 崩塌至 0.075-0.163（其余类目多轮全量均稳定）
- 处置后结论：harness 加 empty_answers 计数 + retries 4 → **empty=0，MS 仍崩塌**
  → 排除限流/空答案伪影，是**真实效应**：全量语料库 top-k 上下文含跨主题噪音，
  干扰 MS 综合生成（干净库 top-5 即含事实 → ctx_n=5 达 0.463 历史最佳）
- 决定性实验（全量 + MS ctx_n=5）：MS Acc 0.0875→0.1375，但 **retr_gap=0.475**
  （事实常不在 top-5 关键词结果内）→ 剪枝伤检索，整体 0.702 持平 → 已回退
- 第三轮（--ingest-all 复现全量语料 + --ms-rerank 词法重排）：
  * A 全量语料无重排：MS=0.113，retr_gap=0（事实在 20 条检索结果内），gen_gap=0.89
    → **语料噪音假说在 harness 层面坐实**（同数据集，干净库 0.44 vs 全量库 0.11）
  * B 全量语料+词法重排取前5：MS=0.125，retr_gap=0.49 → 词法重排救不回
    （问题词与"变化相关"上下文重叠不足；名字匹配淹没信号）
- **最终结论（MS 三分离收官，第四轮补全）**：
  * C 全量语料+语义重排(bge-m3 余弦 top5)：MS=0.138，retr_gap=0.56，gen_gap=0.30
    —— 语义重排同样救不回（"查询-文档"嵌入鸿沟：问题嵌入 vs 证据文本相似度低）
  * D 全量语料+混合选择(关键词 top3 ∪ 语义 top2)：MS=0.138，retr_gap=0.44（retr 最优 0.56）
    —— 检索改善不转化为 Acc：**生成地板是硬约束**
  * 完整系列：A 0.113(retr 1.0/gen 0.89) / B 0.125(retr 0.51) / C 0.138(retr 0.44) / D 0.138(retr 0.56)
    / 干净库 0.44(retr 1.0/gen 0.55) → **MS 生成天花板 ≈0.45**（上下文完美时），
    全量库加检索罚分后 ≈0.11-0.14
  * E 全量语料+两段式生成（先抽候选变化再作答）：MS=0.138，retr=1.0，gen_gap=0.86
    —— 候选提取无法复现期望事实原句（判分是子串/judge 级），两段式也不救
  * **完整系列终表**（全量语料条件，全部策略）：
    | 策略 | MS Acc | retr | gen_gap |
    |---|---|---|---|
    | A 20 条全进 | 0.113 | 1.0 | 0.89 |
    | B 词法 top5 | 0.125 | 0.51 | 0.39 |
    | C 语义 top5 | 0.138 | 0.44 | 0.30 |
    | D kw3∪sem2 | 0.138 | 0.56 | 0.43 |
    | E 两段式 | 0.138 | 1.0 | 0.86 |
    | F 覆盖性验证(候选补全) | 0.138 | 1.0 | 0.86 |
    | G LLM 重排(reason mode) | 0.100 | 1.0 | 0.90 |
    | 干净库 top5 | 0.44 | 1.0 | 0.55 |
  * G 模型层实证（50q 全量语料 × deepseek-reasoner）：MS=0.26（chat 平台 0.11-0.14 的 ~2 倍；
    排除 12 个空答案后 ~0.34）—— 小样本增益
  * H ★reasoner 线上化全量验证（500q，MS=reasoner+240s）：MS=0.125、整体 0.700 ——
    **50q 的 0.26 未放大**，与 chat 全量平台（MS 0.09-0.14 / 整体 0.702）无显著差异；
    **线上化决策：回退 chat**（reasoner 加成本不加全量收益）。教训：小样本模型对比
    结论必须先全量复验再线上化（与"干净库≠全量库"同族）
  * 终局结论：MS 平台与模型/检索/提示/判分/重排全部弱相关——生成结构系统性限制，研究级
  * I 终局实验（reasoner+240s+覆盖验证协同，50q）：MS=0.12、empty=0 —— 最强模型+覆盖
    补全协同仍落平台。**MS 九数据点彻底闭合**（7 策略 × 2 模型 + 协同组合）
  * **终极结论**：MS 全量库 ≈0.10-0.14 为稳定平台（9 数据点）；生成天花板 ≈0.45
    且干净库条件下生成缺口仍 55% —— 剩余路径（专训检索器/完整性 judge 在生成
    改善后复测/两段式+判分协同）属 GEN-3/CH-1 研究范畴，本系列基线齐备
- 方法论沉淀：类目级结论必须独立跑验证；全量评测需 empty 追踪；配置改动必须看
  全量口径（干净库结论 ≠ 全量库结论）
