# Roadmap

## v6.36 (Current) — Initial Release ✅

- [x] Three-tier memory architecture (Retrieval / Memory / Guardian)
- [x] 47 retrieval channels with progressive cascading
- [x] 50-level Guardian chain
- [x] Multi-modal support (text, image, audio)
- [x] MCP Server (stdio + SSE)
- [x] REST API + Web Dashboard
- [x] Multi-tenant isolation
- [x] Docker deployment

## v6.37 — Developer Experience

- [ ] Improved error messages and debugging
- [ ] Async API support
- [ ] Better type hints and IDE integration
- [ ] Performance profiling tools
- [ ] CLI autocomplete
- [ ] `trinity-config` CLI wizard for first-time setup

## v6.38 — Cross-Platform Enhancement

- [ ] Windows native service (Windows Service)
- [ ] macOS launchd integration
- [ ] Linux systemd service file
- [ ] Daemon auto-update mechanism

## v6.39 — Production Hardening

- [ ] Connection pooling for PostgreSQL adapter
- [ ] Redis caching layer
- [ ] Rate limiting for API endpoints
- [ ] Audit logging system
- [ ] Prometheus metrics export

## v6.40 — Multi-Agent Collaboration

- [ ] Agent-to-agent (A2A) memory sharing protocol
- [ ] Distributed memory sync across nodes
- [ ] Conflict resolution for concurrent writes
- [ ] Cross-agent context handoff

## Future (No Timeline)

- **SaaS API**: Hosted memory service with pay-as-you-go pricing
- **Enterprise Console**: Web admin dashboard for tenant management
- **Plugin System**: Third-party adapter plugins
- **Cloud Native**: Helm chart for Kubernetes deployment
- **Edge Runtime**: WASM-compatible client for edge devices
- **Mobile SDK**: iOS / Android memory client
- **Model Context Protocol v2**: Support for upcoming MCP spec changes

---

*This roadmap is a living document. Priorities may shift based on community feedback and contributions.*
